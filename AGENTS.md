# GPT project bootstrap — Codex instructions

This is a public, organization-neutral bootstrap kit. It is not an organization's live policy, and opening it grants no authority over any repository, account, connector, operations system, or production environment.

## Before doing setup work

- Read `README.md`, `START-CODEX-ORG.md`, and `CODEX-ORG-OPERATING-SYSTEM.md` in full.
- Treat every angle-bracketed value as an unresolved template variable unless the user has supplied and confirmed it.
- Never infer that the repository owner, current GitHub identity, or current organization is the user's intended target.
- Never write organization-specific names, people, identifiers, private URLs, credentials, or generated policy back into this public bootstrap repository.
- Do not access or mutate external systems merely because this repository was opened.

## When the user asks to bootstrap an organization

- Follow `START-CODEX-ORG.md` first, then the detailed operating-system blueprint.
- Guide human-only prerequisites one step at a time and wait for confirmation.
- Verify identities, repositories, permissions, and external state through approved live tools; do not rely on memory.
- Never request passwords, access tokens, private keys, or other credentials.
- Keep discovery and auditing read-only until the user approves exact proposed writes.
- Generate organization-specific policy in the user's chosen canonical repository, not here.
- Treat technical capability as distinct from user authorization.
- Stop and explain the blocker if required tools, permissions, or context are unavailable.

## Contributions to this repository

Keep changes reusable and organization-neutral. Do not add real organization names, personal names, internal identifiers, private links, customer or production data, or instructions that silently authorize external writes.
